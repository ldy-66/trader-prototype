# 截图基线与待确认范围

## 已从截图确认

- 约 4:3 的桌面窗口形态，顶部标题栏、左侧一级导航、内容工作区三层结构。
- 一级导航包含：行情、交易、融券、数据、风控、策略、配置、审批、系统。
- 行情与交易页右侧固定组合五档行情和交易下单面板。
- 主内容以高密度表格、页签、筛选器、浅灰斑马纹和蓝色选中态为主。
- 买入使用橙红色强调，卖出使用青绿色强调。

## 当前原型中的实现边界

- 只复刻用户可见页面与局部前端交互，不代表真实 OMS 校验、路由、风控或报盘逻辑。
- 截图中的人员、客户、账号、框架、机构等内部数据未原样复用，已替换为演示数据。
- 未获得清晰截图或用户手册支撑的页面不补造字段与流程。

## 后续优先补充材料

1. 行情页选择标的后，右侧行情和下单面板联动的完整状态。

3. 订单类型、订单模式、空头交易、敞口控制交易的下拉选项及字段差异。
4. 委托详情、撤单确认、批量下单、成交与子单联动。
5. 策略、审批、系统页面截图。
6. 各页面窗口缩放、列拖动、横向滚动与弹窗样式。
